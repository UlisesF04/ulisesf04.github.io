# Ulises Fernández — Personal portfolio

## Objective

This portfolio presents my background as an advanced Computer Science and Software Development student and showcases how I apply my skills to practical projects.

The goal is to make my work easy to explore through clear descriptions, screenshots, live demos, and source code. The responsive interface is available in English and Spanish and supports keyboard navigation and reduced-motion preferences.

## Tech stack

| Technology | Purpose |
|---|---|
| React 19 | Component-based interfaces, state management, and language switching with Context API |
| JavaScript and HTML5 | Application logic and semantic page structure |
| CSS3 | Responsive layouts, custom properties, gradients, and transitions |
| Vite 8 | Development tooling and production builds |
| Node.js and npm | Build tooling and dependency management |
| Lucide React | Interface icons |
| Fontsource | Self-hosted Manrope and DM Sans fonts |
| Sharp and WebP | Optimized portraits and project screenshots |
